# Blog Post 2: NHL scoring and winning percentage

Author: Rui Bao

## Question
Compare the association of total goals scored and goal differential with the reported winning percentage of historical NHL team-seasons.

## Data source and scope
https://www.scrapethissite.com/pages/forms/

The script requests pages 1–24 with the website's default page size, preserving the scope of the original project. It does not claim these pages exhaust the site or every season. Actual row counts, year coverage, removed incomplete rows, and observations by year are generated in results. The site is a teaching sandbox, not an official NHL statistical release. Records have not been independently verified against NHL records.

## Reproduce
1. Place index.qmd and this README in blog/posts/post2 within the Quarto website.
2. Install R and Quarto/RStudio. Install packages in R:
   install.packages(c("rvest", "dplyr", "readr", "ggplot2", "knitr", "rmarkdown"))
3. Open index.qmd in RStudio and click Render. Alternatively, from the website root run:
   quarto render blog/posts/post2/index.qmd
4. The first execution needs internet access and fetches 24 pages sequentially, waiting one second before each new request. Later renders read the saved HTML and need no website requests for the data.
5. Commit the resulting source snapshots, clean data, charts, results, README, and index.qmd. Publish the rendered website through the existing workflow.

## Responsible collection
Use only the public practice pages. Check the site's current access guidance before a new scrape. Do not bypass logins, CAPTCHAs, paywalls, or blocks. The code stops when expected team rows are absent; inspect the page manually if this happens. It does not retry aggressively. No credentials or personal data are collected.

To intentionally refresh the data, first archive the existing data/raw folder, then remove the corresponding HTML files and their metadata CSVs together before rendering. Do not refresh routinely: use snapshots for reproducibility.

## Files
- index.qmd: article and all R code.
- data/raw/page_XX.html: source page snapshots.
- data/raw/page_XX.html.csv: URL and actual retrieval timestamp for each page.
- data/raw/hockey_raw.csv: combined extracted text before cleaning.
- data/clean/hockey.csv: cleaned team-season data and goal differential.
- figures/: two PNG charts generated by code.
- results/correlations.csv: Pearson correlations.
- results/sample_summary.csv: coverage and cleaning counts.
- results/observations_by_year.csv: number of analyzed team-seasons by year.
- results/retrieval_log.csv: combined provenance records.
- results/sessionInfo.txt: R and package versions.

The website stores rendered HTML and its display assets under docs, as specified in the project's _quarto.yml.

## Methods and limitations
Trim team names, parse numeric fields, remove and count incomplete records, check unique team-year keys and valid nonnegative counts, and compute goals_for minus goals_against. Use the source's winning percentage as reported, not wins divided by wins plus losses. Ties and overtime records are not collected.

Correlations and charts describe the same completed seasons; they are not causal estimates or out-of-sample forecasts. Totals are not standardized by games played, so season length and changing scoring environments limit cross-season comparisons. Missing fields or changed page structure may require code maintenance. Text statistics are calculated from the current cached data rather than manually copied.
